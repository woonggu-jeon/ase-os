# Purpose

Knowledge Layer는 프로젝트의 모든 사실(Facts)을 정의한다.

Constitution이 "원칙"이라면,

Knowledge는 "사실"이다.

이 계층은 프로젝트의 공통 언어(Ubiquitous Language)를 정의하며,
AI와 개발자는 이 문서를 기준으로 동일한 개념을 이해한다.

---

# Responsibilities

Knowledge Layer는 다음 정보를 관리한다.

- Product
- Domain
- Business
- Architecture Overview
- Terminology

---

# Principles

- 사실만 기록한다.
- 구현을 기록하지 않는다.
- 의견을 기록하지 않는다.
- 중복 정의하지 않는다.
- 용어는 하나의 문서에서만 정의한다.
